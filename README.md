# 🍝 Basilico

Премиальный лендинг для ресторана итальянской кухни, созданный как демонстрационный кейс для веб-студии. Проект сочетает в себе элегантный дизайн уровня Fine Dining и современную техническую архитектуру.

Пользователь может ознакомиться с меню, узнать часы работы и забронировать стол. Заявки с формы моментально улетают в Telegram-бот администратора.

## 🚀 Технологический стек

*   **Frontend:** HTML5, Vanilla JavaScript, Tailwind CSS, Handlebars (шаблонизатор для переиспользования компонентов).
*   **Сборка:** Vite (многостраничная сборка).
*   **Backend / Serverless:** Cloudflare Pages & Functions (Node.js).
*   **Интеграция:** Telegram Bot API (для приема заявок с сайта).
*   **Деплой:** Cloudflare Pages (CI/CD из GitHub).

## ✨ Ключевые особенности реализации

*   **Безопасный бэкенд:** Отправка заявок в Telegram вынесена на серверные функции Cloudflare (`/api/send-telegram`). Токен бота надежно скрыт от пользователя и не хранится в клиентском коде.
*   **Умная форма бронирования:** Сбор не только имени и телефона, но и даты, времени и количества гостей. Реализована строгая валидация: проверка на корректность имени (только буквы), формата телефона, а также защита от выбора даты в прошлом или времени вне диапазона 00:00–23:59.
*   **Интерактивное меню:** Вкладки с категориями блюд (Antipasti, Primi, Secondi и др.) переключаются на лету без перезагрузки страницы.
*   **Доступность (A11y) и UX:** 
    *   Полноценное мобильное меню с плавной анимацией выезда.
    *   Модальное окно бронирования с затемнением фона и закрытием по клику вне области или по клавише `Escape`.
    *   Анимации появления блоков при скролле (`IntersectionObserver`).
    *   Плавное скрытие плавающей кнопки бронирования при приближении к футеру.
*   **SEO и соцсети:** Настроены Open Graph теги (для красивого превью в Telegram и WhatsApp) и Favicon.
*   **Адаптивность:** Mobile-first подход. Дизайн безупречно выглядит как на смартфонах, так и на больших мониторах.

## 📦 Развертывание

Проект настроен на автоматический деплой через Cloudflare Pages.

Для локальной разработки:
1.  `npm install`
2.  `npm run dev`

Для тестирования серверных функций локально используется `npx wrangler pages dev dist`. 
*(Потребуется файл `.dev.vars` с ключами `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`).*
